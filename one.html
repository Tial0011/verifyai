01 — css transforms

CSS already speaks 3D.

The browser has shipped real, depth-sorted 3D in CSS for over a decade: perspective, transform-style: preserve-3d, rotateX/Y/Z. This orrery contains no canvas and no WebGL context — every ring, tick and satellite is an ordinary <div> positioned in three dimensions. Drag it: the tilt you feel is CSS doing the math.

02 — canvas + math

Or write your own engine.

Under all 3D there is only arithmetic. Take twelve points, spin them, divide by depth, draw thirty lines. That divide — s = f / (f + z) — is the entire secret of perspective. The nearest vertex prints its live rotated coordinates; drag the solid and watch the numbers flip.

03 — notes

And the browser ships a GPU.

WebGL has lived in every major browser since 2011. Libraries like Three.js sit on top of it for convenience — but the API itself is plain JavaScript: getContext('webgl'), shader strings, typed arrays, draw calls. The hero at the top of this page is exactly that, and nothing else. Open devtools → network: after two typefaces, zero requests.

// the lighting behind "Yes." — plain GLSL N = normalize(vN); V = normalize(-vP); diff = clamp(dot(N, L), 0.0, 1.0); hl = diff * 0.5 + 0.5; hl *= hl; // wrapped lambert spec = pow(clamp(dot(N, H), 0.0, 1.0), 40.0); rim = pow(1.0 - clamp(dot(N, V), 0.0, 1.0), 2.5); col = base * (0.10 + 0.85 * hl) + spec * vec3(1.0, 0.96, 0.90) + rim * vec3(0.945, 0.290, 0.110); // vermilion edge
